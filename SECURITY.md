# Security policy

`soroban-storage` decides how long contract data lives on-chain, so bugs can
mean lost or archived data. Please report suspected vulnerabilities
privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository instead of opening a public issue.

Include the affected version, a minimal contract or test that shows the
problem, and the impact you expect. You should get a reply within a week.
